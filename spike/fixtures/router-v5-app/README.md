# router-v5-app fixture

Isolated dependency tree pinning GitHub issue #72's exact versions
(`react`/`react-dom` 16.9.0, `react-router`/`react-router-dom` 5.0.1),
separate from the root project's React 19 `node_modules`.

Run `npm install` in this directory before running
`spike/run-phase4d-router-v5.js` — it is not covered by the root project's
own `npm install`.
